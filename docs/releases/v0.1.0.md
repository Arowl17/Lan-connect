First test build of Lan Connect: one mouse and keyboard for your Windows computers over your home network. Move the cursor off the edge of one screen and it appears on the other computer; your keyboard follows it.

## Download

| File | Use it for |
|---|---|
| **LanConnect-Setup-0.1.0.exe** | Recommended. Install it on **every** computer. It also sets up the Windows Firewall rule. |
| **LanConnect-0.1.0-portable.exe** | A single file with no installation. It offers to fix the firewall rule on first start. |

Windows may say the publisher is unknown, because the app isn't code-signed yet. Click **More info** → **Run anyway**.

## Setting up (once)

1. Install and open Lan Connect on both computers. It lives in the notification area (tray).
2. On one computer, the other appears under **Nearby computers**. Click **Pair**.
3. Check that both screens show the same 6-digit code and confirm on both.
4. Choose where the other computer sits: left, right, above or below.

After that they reconnect by themselves, even after restarts.

## What's in this version

- **Mouse and keyboard sharing.** Push the mouse past the screen edge, or press **Ctrl + Alt + arrow** toward the other computer.
- **Game mode.** Screen edges never switch while a game hides or locks the cursor, while a fullscreen app is focused, or while GeForce NOW is focused, and the app stops watching the mouse entirely. The hotkey still works.
- **No accidental switches.** Corners never switch, a small push past the edge is needed, and dragging never switches.
- **No stuck keys.** Keys held on the other computer are always released when control comes back or the connection drops.
- **Solid on Wi-Fi.** A lost packet never loses mouse movement, and clicks land exactly where they were made. If the other computer stops answering, your mouse comes back within about 1.5 seconds.
- **Secure.** Pairing uses a 6-digit code like Bluetooth. After that, only paired computers can connect, and everything is encrypted.
- **Tray icon** with a status color, quick switching, pause, and a game mode toggle.

## Known limitations

- This is the first build. It passes 83 automated tests on Windows but hasn't been tried on real hardware yet, so please report anything odd.
- On the computer being controlled, admin windows (Task Manager, UAC prompts) can't be clicked yet.
- Clipboard sharing (copy on one computer, paste on the other) is coming in the next version.

## Something wrong?

Logs are in `%LOCALAPPDATA%\LanConnect\logs` (Settings → **Open log folder**). The README has a troubleshooting section for firewall and Wi-Fi problems.
