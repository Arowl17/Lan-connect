**Game mode now knows when you're playing and when you're in the game's menu.** Made for borderless games like Skyrim.

## Download

| File | Use it for |
|---|---|
| **LanConnect-Setup-0.2.1.exe** | Recommended. Install it over 0.2.0 on the computer you play on (installing it on both is fine too). Your pairing and settings are kept. |
| **LanConnect-0.2.1-portable.exe** | A single file with no installation. |

## Fixed: games like Skyrim

Skyrim hides the cursor but never locks it, in its menus as well as while you play. So the invisible cursor wandered onto your other screen while you looked around, and game mode couldn't tell the menu from playing.

- **While you play, the mouse stays on the game's screen.** No more hovering, scrolling or clicking on your other monitor, and no switching to the other computer.
- **Press Esc and the mouse is free.** Open the game's menu with Esc and you can move over to your other screen or to the other computer. Press Esc again to go back to the game and the mouse is held again.
- When the menu opens, the cursor starts in the middle of the game's screen, so a small nudge never sends it somewhere unexpected.
- Walking in the game (holding W, A, S or D) also counts as playing, which corrects things if a menu was closed with another key.
- After leaving a game (Alt + Tab), the cursor first has to come away from the screen edge before it can switch computers. Before, a cursor the game had left pinned against the edge could jump straight to the other computer.

Both new behaviours can be turned off in Settings → **Game mode**. Apps in the game-mode list (GeForce NOW by default) still never switch, even in a menu.

## Something wrong?

Logs are in `%LOCALAPPDATA%\LanConnect\logs` (Settings → **Open log folder**). Lines about "Keeping the cursor on the game's screen" and "Cursor free again" show what game mode did.
