**Copy and paste between your computers.** Copy something on one computer, move the mouse over, and paste on the other. It works in both directions.

## Download

| File | Use it for |
|---|---|
| **LanConnect-Setup-0.2.0.exe** | Recommended. Install it over 0.1.0 on **both** computers. Your pairing and settings are kept. |
| **LanConnect-0.2.0-portable.exe** | A single file with no installation. |

Both computers need 0.2.0 for copy and paste to work.

## New: shared clipboard

- **Text**, including formatting from browsers, Word and Outlook.
- **Images and screenshots.** Win + Shift + S on one computer, paste on the other.
- **Files and folders.** Ctrl + C in File Explorer, then Ctrl + V in a folder on the other computer. Big copies show a notification when they're ready to paste.
- The clipboard travels when control moves to the other computer, and only if you copied something new.
- Passwords copied from a password manager stay out of clipboard history on the other computer too.
- Settings → **Clipboard** lets you turn it off, leave files out, or change the largest file transfer (1 GB by default).

## Also in this version

- A computer that connects while the other is still starting no longer creates a duplicate connection that could drop a switch in progress.
- More robust handling when Windows is busy: a slow reply right after switching no longer bounces control back, and missed key or button releases can't cause stray clicks.

## Something wrong?

Logs are in `%LOCALAPPDATA%\LanConnect\logs` (Settings → **Open log folder**).
